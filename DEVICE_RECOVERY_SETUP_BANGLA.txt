Hisab360 — আগের ডিভাইস পুনরুদ্ধার

Admin-এর কাজ (একবার):
1. এই প্যাকেজের নতুন Device_Permission_Rules.json ফাইলের সব লেখা Copy করুন।
2. Firebase Console → collection-app-479e0 → Realtime Database → Rules খুলুন। পুরোনো Rules-এর কপি রেখে নতুন Rules বসিয়ে Publish চাপুন।
3. অ্যাপ Refresh করুন। ডাটার JSON Import/Delete করতে হবে না।

প্রত্যেক ব্যবহারকারীর কাজ (অনুমোদিত ডিভাইসে একবার):
1. Login করে উপরের “ডিভাইস সুরক্ষা” চাপুন।
2. সম্মতি দিলে Hisab360_Device_Recovery_ID.json নামে একটি ব্যক্তিগত ফাইল Download হবে। ফাইলটি ফোনের Downloads বা নিজের নিরাপদ জায়গায় রাখুন।
3. ফাইলটি অন্য কাউকে দেবেন না। এটি Password-এর মতো গোপন রাখুন।

Browser site data মুছে গেলে:
1. Login পেজে নিজের User ID এবং Password লিখুন।
2. “আগের ডিভাইস পুনরুদ্ধার” চাপুন; আগে Download করা recovery file বাছুন।
3. সফল হলে Login চাপুন। আগের ডিভাইসের UID ও অনুমোদন ফিরবে; Admin-এর নতুন অনুমোদন প্রয়োজন হবে না।

Block/Delete/অ্যাকাউন্ট বন্ধ থাকলে recovery তা অতিক্রম করবে না। মূল admin ছাড়া অন্য ID-তে নতুন সেশন চালু হলে পুরোনো ডিভাইসের সেশন বন্ধ হবে।

Recovery file আগে সংরক্ষণ না করলে অথবা ফাইল হারিয়ে ফেললে browser data সম্পূর্ণ মুছে যাওয়ার পরে পরিচয় স্বয়ংক্রিয়ভাবে উদ্ধার করা যায় না। সে ক্ষেত্রে Admin-এর নতুন অনুমোদন প্রয়োজন হতে পারে।
এই ফাইল পরিচয় ফেরানোর গোপন চাবি; ফোনের hardware-এর সঙ্গে বাঁধা নয়। এটি শেয়ার করলে অন্য ফোনেও পরিচয় ফেরানো সম্ভব হতে পারে, তাই শেয়ার করবেন না।

নতুন Rules Publish না হওয়া পর্যন্ত অ্যাপ চলবে, কিন্তু ডিভাইস সুরক্ষা থেকে recovery file তৈরির কাজ চালু হবে না।
